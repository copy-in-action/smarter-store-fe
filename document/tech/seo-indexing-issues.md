## 2. 도메인별 상세 현황

### 2.1 메인 도메인 (ticket.devhong.cc)

#### 인프라
- **호스팅**: 개인 서버
- **CDN**: Cloudflare
- **배포 방식**: Cloudflare를 통한 프록시

#### 구글 검색 콘솔 상태
- **등록**: ✅ 완료
- **과거 색인**: ✅ 메인 페이지 색인 및 검색 가능했음

  - `/sitemap.xml` (메인 사이트맵 인덱스)
  - `/sitemap/sitemap.xml` (정적 페이지)
  - `/sitemap/performance/[id].xml` (동적 공연 페이지)

#### 검증 결과
- **HTTP 헤더**: ✅ 정상
- **사이트맵 유효성**: ✅ 외부 검증 사이트에서 정상

- **수집 상태**: ✅ **35개 페이지 수집 완료** ⭐
- **수집 오류**: ✅ **0개 (오류 없음)** ⭐
- **검색 노출**: ⚠️ 메인 페이지만 검색 결과에 노출

  - ✅ 메인 페이지 표시
  - ✅ **공연 상세 페이지 다수 표시** (2026 Apink 8th Concert, 영동포아트홀 기획공연, 슈퍼월리버드 등)

## 4. 문제 분석

### 4.1 가능한 원인

#### 4.1.1 ~~Cloudflare 크롤러 차단 (메인 도메인)~~ ❌ 기각

**가설**: ~~Cloudflare 설정이 검색 엔진 크롤러를 방해~~

**검증 결과**: ❌ **기각됨**
- ✅ 네이버가 메인 도메인에서 **35개 페이지 수집 성공**
- ✅ 수집 오류 0개
- ✅ 크롤러는 정상 접근 가능

**결론**: Cloudflare는 크롤러를 차단하지 않음. 문제는 **"수집"과 "색인/노출"의 차이**

---

#### 4.1.2 도메인 신뢰도 차이 (메인 vs 테스트 도메인) ⭐ 가능성 높음

**가설**: 네이버가 메인 도메인(ticket.devhong.cc)보다 Vercel 도메인을 더 신뢰

**근거**:
- ✅ 메인 도메인: 35개 수집, 메인만 검색 노출
- ✅ Vercel 도메인: 수집 + **공연 상세도 검색 노출**
- 📊 동일한 콘텐츠, 다른 검색 노출 = **도메인 품질 점수 차이**

**네이버 검색 노출 요인**:
- 도메인 나이 (Vercel은 vercel.app으로 높은 신뢰도)
- 도메인 품질 점수
- 백링크 (외부 링크)
- 사용자 행동 데이터 (클릭률, 체류시간)
- 콘텐츠 신선도

**점검 필요 항목**:
- [ ] 도메인 등록일 확인 (ticket.devhong.cc는 언제 등록?)
- [ ] 외부 링크(백링크) 수 확인
- [ ] 네이버 웹마스터에서 사이트 품질 점수 확인
- [ ] 콘텐츠 업데이트 주기 확인

#### 4.1.3 구글 사이트맵 접근 문제

**가설**: 구글이 사이트맵을 파싱하지 못함

**증거**:
- ❌ 구글: "가져올 수 없음" 상태
- ✅ 네이버: 35개 수집 성공 (같은 사이트맵)

**점검 필요 항목**:
- [ ] 구글 전용 사이트맵 생성 (단순화)
- [ ] 사이트맵 응답 속도 개선
- [ ] 사이트맵 헤더 확인 (Content-Type: application/xml)
- [ ] robots.txt에서 사이트맵 URL 확인

#### 4.1.4 신규 도메인 샌드박스 효과

**가설**: 메인 도메인이 신규 도메인이라 검색 노출 제한

**근거**:
- 네이버는 신규 도메인에 대해 "샌드박스" 적용 가능
- 수집은 되지만 검색 노출은 제한
- 일정 기간(3-6개월) 후 정상 노출

**점검 필요 항목**:
- [ ] 도메인 등록일 확인
- [ ] 네이버 웹마스터 등록일 확인
- [ ] 3개월 이상 운영 여부

### 4.2 Vercel 도메인에서의 성공 요인

**네이버에서 공연 상세가 검색 노출된 이유**:
- ✅ **vercel.app 도메인의 높은 신뢰도** ⭐ (핵심 차이)
- ✅ Vercel Edge Network의 빠른 응답 속도
- ✅ 검색 엔진 봇에 최적화된 인프라
- ✅ SSR (Server-Side Rendering) 정상 작동
- ✅ JSON-LD 구조화 데이터 정상 파싱
- ✅ OG 이미지 정상 로딩

**구글에서 일부만 색인된 이유** (메인, 로그인만):
- ⚠️ 크롤링 예산 (Crawl Budget) 제한 가능성
- ⚠️ 신규 도메인이라 색인 우선순위 낮음
- ⚠️ 사이트맵 "가져올 수 없음" 상태로 인한 크롤링 제한

### 4.3 핵심 결론

**메인 도메인 문제**:
1. ❌ ~~Cloudflare가 크롤러 차단~~ (기각)
2. ✅ **네이버는 수집 성공, 검색 노출만 제한** (도메인 신뢰도 문제)
3. ❌ 구글은 사이트맵 접근 실패 (기술적 문제)

**해결 방향**:
1. **단기**: 구글 사이트맵 문제 해결
2. **중기**: 메인 도메인 신뢰도 향상 (백링크, 콘텐츠 업데이트)
3. **장기**: Vercel로 전환 또는 메인 도메인 지속 사용 판단

## 5. 다음 액션

### 5.1 긴급 조치 (Critical Priority) 🔴

#### 구글 사이트맵 문제 해결

- [ ] **사이트맵 단순화 테스트**
  - [ ] 정적 사이트맵만 등록 (/sitemap/sitemap.xml)
  - [ ] 동적 사이트맵은 제외 (임시)
  - [ ] 24시간 후 상태 확인

- [ ] **구글 검색 콘솔 재검증**
  - [ ] 기존 사이트맵 제거
  - [ ] 새 사이트맵 재제출
  - [ ] URL 검사 → 색인 생성 요청 (메인 페이지)
  - [ ] URL 검사 → 색인 생성 요청 (공연 상세 5개)

- [ ] **사이트맵 응답 속도 확인**
  - [ ] curl -w "@curl-format.txt" https://ticket.devhong.cc/sitemap.xml
  - [ ] TTFB (Time To First Byte) < 500ms 목표

#### 네이버 검색 노출 개선

- [ ] ~~**Cloudflare 설정 점검**~~ (필요 없음, 크롤링 정상)

- [ ] **도메인 신뢰도 향상**
  - [ ] 외부 링크(백링크) 확보
    - 네이버 블로그/카페에 링크
    - 관련 커뮤니티에 소개
  - [ ] 콘텐츠 정기 업데이트
    - 주 2-3회 신규 공연 등록
    - 기존 공연 정보 업데이트
  - [ ] 네이버 웹마스터에 전체 사이트맵 등록
    - /sitemap/sitemap.xml (정적)
    - /sitemap/performance/0.xml (공연)
